# Personal Diet and Budget Project

Beginner-friendly Python starter for tracking daily calories.

## Project structure

- `main.py`: runnable demo entry point
- `models.py`: core data models (`User`, `Food`, `Meal`)
- `tracker.py`: calorie math and `DietTracker` logic
- `requirements.txt`: dependency note (no external packages needed)

## Run

```bash
python main.py
```
